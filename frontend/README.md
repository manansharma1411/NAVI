# NAVI — Frontend Dashboard

## Scope & Responsibility
The `frontend/` package houses the web control center for NAVI.

### Planned Capabilities
- **Goal Submission Console**: Interface for users to input high-level tasks, constraints, and instructions.
- **Real-Time Telemetry Stream**: Live view of agent execution steps, DOM attention targets, and reasoning logs.
- **Human-in-the-Loop Controls**: Ability to pause execution, approve high-risk actions, or manually take over browser control.
- **Session History & Inspection**: Post-run audit reports, latency metrics, and verification highlights.

*Implementation scheduled for Phase 5.*

# NAVI — AI Reasoning Backend

## Scope & Responsibility
The `backend/` package contains the agent intelligence, orchestration logic, and multi-modal reasoning engine.

### Planned Capabilities
- **Hierarchical Planner**: Breaks user objectives down into coherent multi-step browser strategies.
- **Perception & Grounding Engine**: Correlates visual viewport frames with semantic DOM elements to resolve target interactables.
- **State Machine & Recovery**: Monitors task progression, verifies step success, and handles page mutations or unexpected popups.
- **Safety Policy & Guardrails**: Validates generated actions against safety boundaries before dispatching to the extension.

*Implementation scheduled for Phase 4.*

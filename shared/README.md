# NAVI — Shared Contracts & Schemas

## Scope & Responsibility
The `shared/` package contains protocol definitions, data models, and schemas shared across the frontend, extension, and backend.

### Planned Capabilities
- **Action Schemas**: Strongly-typed schemas for actions (`ClickAction`, `TypeAction`, `NavigateAction`, `ScrollAction`, etc.).
- **Observation Models**: Schemas for DOM nodes, element bounding boxes, viewport dimensions, and screenshots.
- **WebSocket Protocol**: Message framing, event types, error payloads, and handshake sequences.
- **Shared Constants**: Status codes, timeouts, and configuration bounds.

*Implementation scheduled for Phase 2.*
